# SHAH CAT Official Airdrop Policy v1.0

**정책명:** SHAH CAT Community Growth & Airdrop Policy  
**버전:** v1.0  
**기준 토크노믹스:** SHAH CAT Tokenomics v0.6  
**총 발행량:** 1,000,000,000 SHAH  
**커뮤니티 성장 배정:** 50,000,000 SHAH / 총량의 5%  
**1차 캠페인 예산:** 최대 2,000,000 SHAH  

## 1. 목적

SHAH CAT 에어드랍은 단순 무료 배포가 아니라 프로젝트와 커뮤니티에 실제 가치를 제공한 참여자에게 지급하는 기여 보상 프로그램으로 운영한다.

커뮤니티 성장 배정 50,000,000 SHAH 안에서 캠페인별 예산을 사전 승인하고, 검증된 활동·콘텐츠·테스트·개발 기여에 따라 지급한다.

## 2. 기본 원칙

1. 커뮤니티 에어드랍은 원칙적으로 Community Growth 50,000,000 SHAH 배정에서 집행한다.
2. 게임 보상, 개발비, 유동성 물량과 같은 성과에 중복 지급하지 않는다.
3. 단순 가입보다 실제 활동과 검증 가능한 기여에 높은 보상을 배정한다.
4. 사전 승인된 캠페인 예산 안에서만 지급한다.
5. 미사용 물량은 자동 이월하지 않고 Community Growth 준비금에 잔류한다.
6. 동일 기여에 중복 보상하지 않는다.
7. 가격 상승, 상장, 투자수익, 원금 또는 현금가치를 보장하지 않는다.
8. 캠페인 종료 후 총예산·실지급량·수령자 수·잔여량을 가능한 범위에서 공개한다.

## 4. 지급 기준

### 신규 참여

공식 커뮤니티 가입, 기본 프로필 설정, Solana 지갑 주소 등록, 프로젝트 기본 안내 확인을 완료한 참여자에게 최초 1회 지급할 수 있다.

**기본 보상: 500 SHAH**

단순 가입 반복, 다중 계정, 자기추천은 인정하지 않는다.

### 커뮤니티 활동

| 활동 | 보상 |
| --- | ---: |
| 유의미한 질문 | 100~300 SHAH |
| 다른 회원에게 유용한 답변 | 200~500 SHAH |
| 프로젝트 관련 정보글 | 500~1,500 SHAH |
| 기술·토크노믹스 분석글 | 1,000~3,000 SHAH |
| 고품질 장문 콘텐츠 | 최대 5,000 SHAH |

의미 없는 단문, 반복 댓글, 도배성 활동은 보상하지 않는다.

### 외부 홍보

인정 채널은 네이버 블로그·카페, X, Discord, Reddit, YouTube, TikTok, Threads 및 운영진이 승인한 기타 채널이다.

| 활동 | 보상 |
| --- | ---: |
| 단순 소개 게시글 | 500~1,000 SHAH |
| 직접 작성한 상세 소개글 | 1,000~3,000 SHAH |
| 기술 분석 콘텐츠 | 3,000~5,000 SHAH |
| 자체 제작 영상 | 3,000~10,000 SHAH |
| 고품질 장문 리뷰 | 3,000~10,000 SHAH |

조회수만으로 보상을 결정하지 않으며 품질, 정확성, 독창성, 실제 기여도를 함께 평가한다.

## 5. SHAH Contribution Score

필요한 경우 다음 점수제를 사용할 수 있다.

| 활동 | 점수 |
| --- | ---: |
| 최초 가입 | 1 |
| 정상 커뮤니티 활동 | 1 |
| 유의미한 댓글·답변 | 1 |
| 자체 게시물 | 3 |
| 외부 홍보글 | 5 |
| 밈·이미지 제작 | 5 |
| 영상 제작 | 10 |
| 테스트 리포트 | 10 |
| 버그 발견 | 20 |
| GitHub 기여 | 20~100 |

월 승인 캠페인 예산을 B, 개인 검증 점수를 s, 전체 승인 점수를 S라 할 때:

`개인 지급량 = B × s ÷ S`

일반 커뮤니티 캠페인의 개인 상한은 원칙적으로 해당 캠페인 예산의 2%로 한다.

버그바운티와 주요 개발 기여는 별도 승인으로 이 상한을 달리 적용할 수 있다.

## 6. 연속 참여 및 Contributor 등급

일회성 참여보다 지속적인 검증 기여를 우대할 수 있다.

- 1개월 정상 활동: 기본 보상
- 2개월 연속 활동: +5%
- 3개월 연속 활동: +10%
- 6개월 이상: 별도 Contributor 등급 검토

향후 CAT, SILVER CAT, GOLD CAT, BLACK CAT, SHAH GUARDIAN 등의 기여 등급을 둘 수 있다.

등급은 토큰 보유량이 아니라 검증된 기여를 기준으로 하며 투자 권리, 수익배당권, Treasury 권한을 자동 부여하지 않는다.

## 7. 추천 프로그램

단순 추천만으로 대량 SHAH를 지급하지 않는다.

추천받은 회원이 가입 후 기본 활동을 완료한 경우에만 예를 들어 다음과 같이 지급할 수 있다.

- 신규회원: 500 SHAH
- 추천인: 200 SHAH

추천 보상에는 월 상한을 둔다.

## 8. 부정 참여 금지

다음 행위는 보상 제외 또는 향후 캠페인 참여 제한 대상이다.

- 다중 계정 생성
- 동일인이 여러 지갑으로 반복 신청
- 자기추천
- 허위 SNS 계정
- 콘텐츠 무단 복사
- 동일 게시글 반복 등록
- 봇·자동화 댓글 도배
- 조회수·좋아요·구독자 구매
- 허위 테스트 결과
- 존재하지 않는 버그 제보
- 타인의 작업물 도용
- 허위 GitHub 기여
- 가격 상승·수익 보장 등 허위 투자 홍보

## 9. 신청 정보

에어드랍 신청 시 다음 정보를 받을 수 있다.

- 닉네임
- 커뮤니티 ID
- Solana 지갑 주소
- 참여 캠페인
- 수행한 활동
- 활동 URL
- 제작 콘텐츠 URL
- GitHub ID(해당 시)
- 기여 내용
- 기타 증빙
- 다중 계정·허위 참여 금지 확인

개인키·시드 문구는 어떠한 경우에도 수집하지 않는다.

## 10. 심사 및 지급 절차

1. 참여자가 활동과 증빙을 제출한다.
2. 운영팀이 참여 사실과 품질을 검증한다.
3. 기여 점수 또는 지급량을 산정한다.
4. 중복 계정과 부정행위를 확인한다.
5. 최종 지급 명단을 확정한다.
6. 승인 절차에 따라 SHAH를 지급한다.
7. TXID와 지급 장부를 기록한다.

## 11. 공개 장부

캠페인 종료 후 가능한 범위에서 다음을 공개한다.

- 캠페인명
- 총예산
- 참여자 수
- 승인 참여자 수
- 총 지급량
- 잔여량
- 지급 기준
- 지급 Treasury
- TXID 또는 검증 가능한 거래 기록

개인정보와 개인키는 공개하지 않는다.

## 12. 1차 캠페인 KPI

Genesis Community Airdrop은 토큰 소진량이 아니라 실제 커뮤니티 성과로 평가한다.

- 신규 실제 참여자 100명 이상
- 외부 콘텐츠 50개 이상
- Wallet·Devnet 테스트 30명 이상
- 유효 테스트 리포트 20건 이상
- GitHub·문서 기여 5건 이상
- 30일 재방문율 20% 이상
- 부정 참여 비율 10% 이하

단순 가입자 증가보다 실제 활동 사용자 수를 우선한다.

## 13. 후속 캠페인 확대 기준

1차 캠페인에서 실제 활동 사용자, 재방문, 외부 콘텐츠, 테스트 참여 증가가 확인되고 부정 계정 통제가 가능하면 2차 캠페인을 최대 약 3,000,000 SHAH 수준에서 검토할 수 있다.

성과가 부족하면 다음 캠페인의 예산을 축소하거나 중단한다.

장기적으로 Community Growth 50,000,000 SHAH 전체를 소진하는 것이 목표가 아니다.

예시:

- Genesis Airdrop: 2,000,000 SHAH
- Growth Campaign II: 최대 3,000,000 SHAH
- Expansion Campaign III: 최대 5,000,000 SHAH
- 잔여 물량: 향후 커뮤니티 성장 상황에 따라 보존

## 14. 투자 및 가치 관련 고지

SHAH CAT 에어드랍은 프로젝트 참여와 기여에 대한 프로모션·생태계 보상이다.

다음 사항을 보장하지 않는다.

- 투자 수익
- 가격 상승
- 상장
- 현금 환전
- 유동성
- 원금
- 배당
- 이자
- 사업 수익 배분

시장 가격이나 향후 토큰 가치에 대한 보장을 하지 않는다.

## 15. 운영 원칙 요약

> 무료 토큰을 원하는 사람을 모으는 것이 아니라 SHAH CAT을 성장시킬 사람을 모은다.

에어드랍의 목적은 SHAH 배포 자체가 아니다.

커뮤니티, 기술, 콘텐츠, 사용자, 테스터, 개발자를 확보하기 위해 SHAH를 전략적으로 사용한다.
