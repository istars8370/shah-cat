# SHAH 배분 대조와 베스팅 조회

백서 토크노믹스 v0.5를 기존 로컬 Devnet 대시보드의 **배분·베스팅** 메뉴에 연결했다.

## 실행과 사용

1. 최신 저장소를 내려받거나 `git pull`로 갱신한다.
2. `dashboard` 폴더에서 `node server.mjs`를 실행한다.
3. `http://127.0.0.1:4173/#tokenomicsSection`을 연다.
4. T0 이후 월차를 0~36으로 바꿔 예정 해제량과 전체 월별 표를 확인한다.
5. 대조할 개인별 Devnet 공개주소를 입력하고 **Devnet 잔액 대조**를 누른다.
6. 필요하면 **대조 결과 CSV**로 해당 조회의 잔액 비교 기록을 내려받는다.

별도 설치 패키지나 개인키가 필요하지 않다. Mainnet 조회·서명·잠금·전송 기능은 추가하지 않았다. 지갑 연결이나 서명을 요청하지 않고 입력한 공개주소를 로컬 서버를 통해 Devnet RPC에 조회한다. 주소는 앱에서 파일·설정·브라우저 저장소에 저장하지 않는다. 공개주소 입력은 소유권 확인이 아니다.

## 정책 미리보기

- 성재와 동원은 각각 166,666,667 SHAH, T12까지 0, T13~T36에 24회 해제.
- 박원은 166,666,666 SHAH 중 10%인 16,666,666.6 SHAH가 T0에 자유 물량. 나머지 149,999,999.4 SHAH는 T1~T24에 매월 6,249,999.975 SHAH 해제.
- 정수 최소 단위의 누적 내림 산식으로 계산하며 운영자 회차별 최소 단위 오차는 마지막까지 보존한다.
- T0와 실제 베스팅 프로그램은 미확정·미검증이다. 화면은 정책 시뮬레이션이며 실제 잠금·해제·청구 가능량이 아니다. 준비금 50%의 공급은 3인 일정 표에 포함하지 않는다.

## 실제 잔액과 차이의 의미

개인별 주소 매핑이 확인되지 않아 초기 입력값을 비워 두었다. 기존 개발·Treasury 주소를 개인 주소로 간주하지 않는다. 같은 주소를 두 사람에게 입력하면 중복 대조를 거절한다.

차이 = 목표 배분량 − 입력 주소의 현재 SHAH 잔액.

현재 잔액에는 외부 수신·매도·다른 지갑 이동 등이 섞일 수 있다. 따라서 차이는 **이미 지급된 양, 추가 송금 필요량, 배분 완료 증명**이 아니다. 원본 거래와 확인된 개인 주소 매핑을 대조해야 실제 배분 이행을 검증할 수 있다.

빈 주소와 조회 실패는 `미확인`으로 남기고 수량을 0으로 채우지 않는다. 검증된 RPC 응답에서 해당 Mint의 토큰 계정이 없을 때만 0으로 표시한다. 여러 토큰 계정의 잔액을 합산하며 동결 계정 보유분도 포함하고 이를 표시한다. 동결분 포함 잔액은 실제 전송 가능량이 아니다.

조회는 Devnet genesis, Mint의 Token Program·decimals와 실제 발행량, 각 토큰 계정의 Mint·owner·program·정밀도를 검증한다. 실제 발행량이 정책상 10억 개와 다르면 경고한다. `confirmed` 응답은 주소별 슬롯이 다를 수 있어 동일 슬롯의 원자적 전체 스냅샷을 보장하지 않는다.

주소를 수정하거나 새로 조회하면 이전 데이터와 CSV 다운로드를 즉시 무효화한다. 이전 요청의 늦은 응답도 새 주소 결과를 덮어쓰지 못한다.

## CSV 기록

조회 UTC 시각, 정책 버전, Devnet·Mint, 역할 ID, 사용자 입력 주소, 목표량·현재 잔액·차이, 상태와 confirmed 슬롯을 포함한다. 소유권·배분 완료·실제 잠금 검증 플래그는 모두 `false`다. 이 파일은 현재 보유량 대조 기록이며 회계·세무 장부나 전체 전송 이력이 아니다. 주소가 변경되면 새로 대조한 뒤 다시 내려받아야 한다.

## 구현과 검증

- `dashboard/tokenomics.js`: 고정 v0.5 정책과 BigInt 회차 계산, 37개월 표.
- `dashboard/allocation-audit.mjs`: 읽기 전용 Devnet 잔액 대조.
- `GET /api/allocations?seongjae=<주소>&dongwon=<주소>&parkwon=<주소>`: 비어 있는 대상은 생략할 수 있다. 입력이 없으면 RPC 없이 미확인 상태를 반환한다.
- `dashboard/tokenomics-ui.js`: 미리보기, 공개주소 입력, 오류·오래된 응답 처리와 CSV.
- 다른 프로젝트 Mint·decimals 프로필에는 이 SHAH v0.5 정책을 적용하지 않는다.

오프라인 테스트는 `node --test dashboard/*.test.mjs`로 실행한다. 월 경계와 최소 단위 보존, 네트워크 차단, 잘못된 계정·중복 주소, 조회 실패와 실제 0 구분, 주소 변경 중 늦은 응답, CSV 검증 플래그를 확인한다. 모의 RPC 테스트는 실제 3인 주소와 배분 이력을 검증한 것이 아니다.
