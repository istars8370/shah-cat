# Four-Way test automation

This workflow runs Node 22 built-in unit tests when Four-Way research files change, and can be dispatched manually. It uses no secrets, private keys, token transfers or Solana RPC. The workflow file is committed but its run result is not yet verified.

CI passing is a minimum code hygiene signal, NOT evidence of on-chain security, Falcon correctness, audited custody or production readiness. The research release remains NO-GO.
