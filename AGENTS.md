Read `docs/ops/NOW.md`, `docs/ops/BLOCKERS.md` and `docs/ops/AGENTS.md` before selecting work. Inspect current GitHub heads and checks; documents are checkpoints, not substitutes for repository evidence.

- Execute the user's authorized task; ordinary scoped merges/closures explicitly authorized in the current conversation need no repeated approval.

- Preserve stacked PR base dependencies. Verify exact head containment or documented supersession before closing a PR; retain source branches.

- Mainnet deployment, real funds, Treasury movements and changes to signing/authority need separately scoped explicit authorization.
- Never store or request seed phrases/private keys in repository, logs or chat. No automated dependency force-fixes.
- Report exact commit, checks run, failures/skips and remaining blockers. If nothing material changed, report NO MATERIAL CHANGE without a commit.
